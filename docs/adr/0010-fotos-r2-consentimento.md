# 0010. Fotos no R2, com consentimento e sem biometria

- Status: Aceito
- Data: 2026-10-27

## Decisão
- Upload direto do navegador para o R2 com URL pré-assinada; a API só assina.
- Remover EXIF/GPS e corrigir orientação.
- Fotos públicas só com consentimento; fotos privadas da área do sócio via URLs assinadas de curta duração.
- "Fotos em que apareço": marcação manual com opt-in/opt-out. **Sem reconhecimento facial** (dado biométrico, art. 9 do GDPR).
- Exportar e excluir conta disponíveis ao sócio (art. 15 e 17).
