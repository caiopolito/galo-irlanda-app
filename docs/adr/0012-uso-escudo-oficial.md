# 0012. Uso do escudo oficial do Atlético no layout

- Status: Aceito
- Data: 2026-10-27
- Substitui a premissa "Não usar o escudo oficial" de `docs/DESIGN.md`.

## Contexto
O layout original usava apenas o monograma "GI" para evitar uso de marca registrada. O dono do projeto decidiu usar o escudo oficial no layout.

## Decisão
- O escudo oficial do Clube Atlético Mineiro pode ser usado no layout.
- O monograma "GI" continua como marca própria da torcida.
- O aviso legal no rodapé permanece: "Torcida independente de atleticanos na Irlanda. Sem vínculo oficial com o Clube Atlético Mineiro."

## Consequências
- O escudo é marca registrada do clube. Se houver contestação, a troca deve ser simples: o escudo fica em um único componente.
